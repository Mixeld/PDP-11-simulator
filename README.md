# PDP-11-simulator
Симулятор ЭВМ PDP-11 на С. Реализованный в рамках выполнения курсового проекта по операционным системам и системному программированию. 
Финальной цели выполнения нету.

Реализованы:
1) ядро процессора
2) Режим адресации (все 8 режимов реализованы)
3) Инструкции (46 команд)
4) Дизасемблер
5) байтовые операции
6) Терминал
7) Управление памятью
8) Ассемблер
9) Загрузка бинарных файлов

Инфраструктура:
Загрузчик программ (массив слов в память)
Дамп регистров
Дамп памяти
Трассировка выполнения
Базовые тесты
Makefile с раздельной компиляцией (src/build)

Дальнейшее (возможное) развитие:

1) Отладчик
2) Диск
3) MMU
4) GUI 
5) Разработка минимального набора приложения для данного симмулятора
